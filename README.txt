# TechSpecialist Website

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `images/hero.jpg` — replace with your hero photo
- `images/logo.png` — replace with your TechSpecialist logo
- `images/gallery-1.jpg` to `gallery-4.jpg` — replace with actual service photos

## Publish with GitHub Pages
1. Create a GitHub account.
2. Create a new repository, e.g. `techspecialist-website`.
3. Upload `index.html`, `style.css`, and the `images` folder.
4. Open repository **Settings → Pages**.
5. Set the source to **Deploy from a branch**, choose `main` and `/root`, then Save.
6. GitHub will give you a public `github.io` address.
7. Later, connect your own `.com` or `.ph` domain in the same Pages settings.

## Important
The quotation form uses `mailto:` and opens the visitor's email application. For a true online form that works without an email app, we can connect it to Google Forms or another form service later.
